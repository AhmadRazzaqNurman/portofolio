Projek Website E-Commerce Travel

Projek Magang (Agustus - Desember 2025)

Travelola merupakan proyek website e-commerce di bidang travel yang dibuat untuk memudahkan pengguna dalam mencari informasi dan melakukan pemesanan paket perjalanan secara online. Website ini dikembangkan dengan beberapa fitur utama, mulai dari melihat daftar paket perjalanan, memilih detail paket yang diinginkan, melakukan booking, mengelola keranjang, hingga melihat riwayat transaksi. Selain itu, Travelola dilengkapi sistem pembayaran online menggunakan Midtrans agar proses transaksi lebih mudah dan praktis.

  • Mengembangkan website e-commerce travel Travelola menggunakan Vue.js, Vuetify, Laravel, dan MySQL.
  • Membangun fitur pengelolaan paket perjalanan, detail paket, booking, keranjang, dan riwayat transaksi.
  • Mengintegrasikan payment gateway Midtrans untuk mendukung proses pembayaran online.
  • Menerapkan JWT Authentication dan sistem hak akses berdasarkan peran Admin dan User.
  • Mengembangkan REST API untuk menghubungkan frontend, backend, dan database.
  • Mengintegrasikan seluruh fitur untuk mendukung proses pemesanan perjalanan secara terstruktur.

SIREMA – Sistem Rekomendasi Tempat Magang Mahasiswa di Polindra

Proyek Tugas Akhir (Maret - Juli 2026)

Mengembangkan sistem rekomendasi tempat magang mahasiswa berbasis web menggunakan metode Analytical Hierarchy Process (AHP) untuk menentukan bobot kriteria dan Weighted Aggregated Sum Product Assessment (WASPAS) untuk melakukan perangkingan alternatif tempat magang berdasarkan kesesuaian kompetensi, minat mahasiswa, jarak, serta biaya akomodasi dan kehidupan.

  • Menganalisis kebutuhan sistem dan merancang alur proses rekomendasi tempat magang mahasiswa.
  • Mengimplementasikan metode AHP, termasuk perbandingan berpasangan dan pengujian konsistensi menggunakan Consistency Ratio (CR).
  • Mengimplementasikan metode WASPAS untuk normalisasi data, perhitungan nilai preferensi, dan perangkingan alternatif.
  • Merancang dan mengimplementasikan antarmuka serta basis data untuk mendukung proses rekomendasi.
  • Mengembangkan sistem dengan pendekatan Iterative Development melalui tahapan perencanaan, analisis, perancangan, implementasi, dan pengujian.
